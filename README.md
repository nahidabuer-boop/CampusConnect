# CampusConnect 校园网自动连接

适用于 Windows 的校园网认证工具。连接校园网后，填写学校的认证链接和账号密码，程序会在后台检查认证状态，并在认证掉线后尝试重新登录。

## 使用方法

1. 下载并解压项目文件，双击 `CampusConnect.cmd`。
2. 填写学校实际弹出的认证链接、校园网账号和密码。链接需要保留 `ac_id` 参数。
3. 点击「保存并启用自启」。关闭窗口后，程序继续在后台运行。

认证链接格式示例：`https://portal.example.edu/srun_portal_pc?ac_id=20&theme=basic`。请使用学校实际给出的链接。

后台每 10 秒检查一次认证状态，连续两次收到明确的未认证状态后才尝试登录。Windows 任务计划程序在当前用户登录后启动后台程序。需要暂停时，点击「停止并关闭自启」。

## 兼容范围

- Windows 版使用系统自带的 Windows PowerShell、WinForms 和任务计划程序。macOS 和 Linux 暂无版本。
- 支持使用兼容的深澜 SRun 网页账号密码认证，并提供可验证 HTTPS 接口的学校。短信、扫码、统一身份认证跳转和仅支持 HTTP 的登录暂不支持。
- 需要先连上学校的 Wi-Fi 或有线网络。学校的登录入口和认证配置可能不同。

## 凭据与运行状态

配置保存在当前用户的 `%LOCALAPPDATA%\CampusConnect`。密码由 Windows 针对当前用户加密，账号名和认证地址保存在本机配置中。登录凭据只提交到配置地址对应的 HTTPS 认证接口。提交问题时请勿上传本机配置、账号或密码。

## 验证情况

已检查 Windows 界面、SRun 登录参数和北京化工大学校园网认证状态查询。这个分享版的实际掉线重连尚未单独验证，其他学校的兼容性也待实测。
